=== BUKTI AKSES EKSTERNAL lewat MCP bawaan Tabularis (tanpa GUI, tanpa ketik manual) ===

Latar: DBeaver Community terkendala dipakai (lihat catatan di bukti/08 dan
README bagian "Bukti akses internal dan eksternal"), jadi akses eksternal
diwujudkan dengan Tabularis v0.30.0 (gratis, open source Apache-2.0).
Tabularis punya MCP server bawaan dan gratis: `tabularis --mcp`
(stdio JSON-RPC). Transkrip di bawah adalah sesi MCP sungguhan
(waktu setempat 2026-11-01 malam) memakai koneksi tersimpan
"uts_mbd lokal" (127.0.0.1:22122, user backend_dev, db uts_mbd) yang dibuat
sekali lewat GUI. GUI dipakai hanya untuk membuat koneksi itu; semua query
di bawah murni lewat MCP tools/call.

Alat: 5 tool tersedia (list_connections, list_databases, list_tables,
describe_table, run_query). Query identitas memperlihatkan alamat server
172.24.0.2 port 5432, yaitu IP container di jaringan internal Docker,
dijangkau dari luar lewat port mapping host 127.0.0.1:22122.

--- transkrip mentah (probe-wsl) ---
== initialize ==
server: tabularis-mcp v0.1.0

- list_databases(connection_id, output_format)
- list_tables(connection_id, schema, database, output_format)
- describe_table(connection_id, table_name, schema, database, output_format)
- run_query(connection_id, query, database, limit, output_format)
